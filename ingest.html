Go deeper — map a real export.

Drop in one export (CSV or JSON) from a tool your firm uses — a contacts dump, an invoice list, a transactions file. fallkit reads only the shape: the column names and how many records. It never keeps a single value, and it maps that shape onto the owned equivalent, then writes a signed plan you can keep. Nothing is uploaded, stored, or run — it's a plan, not an import.
