## What it is

fallkit is a deterministic, zero-dependency estate tool. Paste the tools a company pays for; fallkit maps each to a real, live owned-equivalent estate build, or says honestly where none exists yet. Slice-zero of the auto-architect. It never throws on hostile input and
produces the same result on every machine.

## API

- `assembleMap`
- `classifyTool`
- `coverageStatement`
